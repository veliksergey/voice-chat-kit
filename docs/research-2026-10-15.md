# Research record: STT, TTS, frameworks, and stack versions (checked 2026-10-15)

Method: npm versions and licenses from registry.npmjs.org dist-tags; pricing from vendor
pricing pages; capabilities from official docs and GitHub. **(v)** = vendor claim, not measured.
**[unverified]** = could not be confirmed from a primary source; treat as a question to settle
at implementation time, not as a fact.

## 0. Claude and audio

No native audio input. The models overview states all current models support text and image
input; the OpenAI-compatibility page states audio input is ignored and stripped. Voice mode in
the Claude apps is consumer-only. Conclusion: an external STT is mandatory; Claude only sees text.
Sources: platform.claude.com/docs/en/models/overview; platform.claude.com/docs/en/cli-sdks-libraries/libraries/openai-sdk.

## 3. Existing abstractions and frameworks

- **Vercel AI SDK** `ai` 7.0.141 (ESM-only, Node ≥22): `transcribe()` (renamed from
  `experimental_transcribe`) covers ~15 providers for batch; `experimental_streamTranscribe`
  covers only 5 models (OpenAI `gpt-realtime-whisper`, Cartesia `ink-2`, ElevenLabs
  `scribe_v2_realtime`, Azure, xAI), server-side only, no browser token flow; `generateSpeech`
  returns a full buffer — **no streaming TTS**. `@ai-sdk/anthropic` 4.0.80 streams Claude text.
  Useful later as one "batch STT" adapter that unlocks many vendors by config.
- **Mastra voice**: 8 STT packages, no streaming STT.
- **LiveKit Agents (Node)** `@livekit/agents` 1.9.3 + `agents-plugin-anthropic`: production-grade,
  but requires a LiveKit server (WebRTC). Overkill for this project.
- **Pipecat**: Python server; JS is client-only. Overkill.
- **Vapi / Retell / ElevenLabs Agents / Deepgram Voice Agent**: hosted pipelines. They do let you
  choose a Claude model: Vapi documents `model.provider: "anthropic"` + `model.model` (listed ids
  include `claude-opus-4-6`, `claude-sonnet-5`; checked 2026-10-15), Deepgram Voice Agent lists
  `claude-sonnet-5`/`claude-sonnet-4-6`/`claude-haiku-4-5` or a BYO endpoint, ElevenLabs Agents
  lists Opus 5.5/Sonnet 5.5 or a custom LLM endpoint, Retell needs a custom LLM WebSocket. What
  their pages do not describe is request-level control (cache breakpoints, effort, fallbacks,
  tools executed on your infrastructure) — **[unverified per platform]**. The decisive point for
  this project: each platform supports only its own STT/TTS vendor list, so none can switch to
  arbitrary or free in-browser libraries, which the request requires.
- **OpenAI Agents realtime**: speech-to-speech on GPT only; cannot use Claude.
- **Hume EVI**: shutting down 2026-11-13.
- `voice-router-dev` 0.9.10, `micdrop`: small multi-provider wrappers; maintenance **[unverified]**.

Verdict: build a thin adapter layer (two interfaces, ~200 lines) over Web Speech and Deepgram,
keep Claude on `@anthropic-ai/sdk` directly, and optionally wrap the AI SDK later for batch STT.
